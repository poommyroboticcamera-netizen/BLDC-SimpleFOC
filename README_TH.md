## ภาพรวม

`BLDC-SimpleFOC` เป็นโปรเจ็กต์การนำฮาร์ดแวร์มาใช้สำหรับไดรเวอร์มอเตอร์ BLDC 3 เฟสแบบกำหนดเองที่ใช้ STM32F405RG เฟิร์มแวร์ปัจจุบันขับเคลื่อนเอาต์พุต PWM เสริมของ TIM1 โดยตรง เพิ่มเวลาตายที่ระดับตัวจับเวลา อ่านผลตอบรับแรงดันไฟฟ้าเฟสด้วยพิน ADC และแสดงคำสั่งอนุกรมอย่างง่ายสำหรับการทดสอบม้านั่งในช่วงแรก

พื้นที่เก็บข้อมูลนี้มีไว้สำหรับการทดสอบอินเวอร์เตอร์แบบควบคุม ไม่ใช่การควบคุมมอเตอร์ในการผลิตที่เสร็จสมบูรณ์ เริ่มต้นด้วยแหล่งจ่ายไฟตั้งโต๊ะแบบจำกัดกระแส รอบการทำงานต่ำ และการตรวจสอบออสซิลโลสโคปก่อนเชื่อมต่อโหลดมอเตอร์จริง

## แผนที่พินฮาร์ดแวร์

### เอาท์พุทพีเอ็มดับเบิลยู

TIM1 ได้รับการกำหนดค่าสำหรับเอาต์พุต PWM ด้านสูงและด้านต่ำเสริม

| เฟสมอเตอร์ | PWM ด้านสูง | PWM ด้านต่ำ | ช่องตั้งเวลา |
| --- | --- | --- | --- |
| คุณ | `PA8` | `PB13` | `TIM1_CH1 / TIM1_CH1N` |
| วี | `PA9` | `PB14` | `TIM1_CH2 / TIM1_CH2N` |
| ว | `PA10` | `PB15` | `TIM1_CH3 / TIM1_CH3N` |

### ข้อเสนอแนะแรงดันไฟฟ้าเฟส

| สัญญาณ | พิน MCU | หมายเหตุ |
| --- | --- | --- |
| แรงดันไฟฟ้าเฟส A | `PA0` | อ่าน ADC 12 บิต |
| แรงดันไฟฟ้าเฟส B | `PA1` | อ่าน ADC 12 บิต |
| แรงดันไฟฟ้าเฟส C | `PA2` | อ่าน ADC 12 บิต |

ขณะนี้เฟิร์มแวร์ใช้ตัวแบ่งแรงดันไฟฟ้าเฟสเป็น:

```cpp
R1_PHASE = 56000.0f
R2_PHASE = 2200.0f
```

ปรับค่าคงที่เหล่านี้ใน `firmware/src/main.cpp` หากค่าตัวต้านทานบนบอร์ดเปลี่ยนแปลง

## ลักษณะการทำงานของเฟิร์มแวร์

เฟิร์มแวร์สร้างงาน FreeRTOS สองงาน:

| งาน | ระยะเวลา | วัตถุประสงค์ |
| --- | ---: | --- |
| `TaskMotorControl` | `1 ms` | อัพเดตรีจิสเตอร์หน้าที่ PWM แบบไซน์ 3 เฟส |
| `TaskMonitor` | `200 ms` | อ่านคำสั่งแบบอนุกรม ตัวอย่าง ADC แรงดันเฟส และพิมพ์การวัดและส่งข้อมูลทางไกล |

ค่ารันไทม์เริ่มต้น:

| การตั้งค่า | ค่าเริ่มต้น |
| --- | ---: |
| ความถี่พีเอ็มดับเบิลยู | `20 kHz` |
| เวลาตาย | `1.5us` |
| หน้าที่เบื้องต้น | `5%` |
| ความเร็วการหมุนเริ่มต้น | `1.0 deg/loop` |
| บอดแบบอนุกรม | `115200` |

## เริ่มต้นอย่างรวดเร็ว

ติดตั้ง VS Code ด้วยส่วนขยาย PlatformIO จากนั้นโคลนและเปิดโปรเจ็กต์เฟิร์มแวร์

```bash
git clone https://github.com/poommyroboticcamera-netizen/BLDC-SimpleFOC.git
cd BLDC-SimpleFOC/firmware
```

สร้างเฟิร์มแวร์:

```bash
pio run
```

อัปโหลดด้วย ST-Link:

```bash
pio run --target upload
```

เปิดมอนิเตอร์แบบอนุกรม:

```bash
pio device monitor -b 115200
```

## คำสั่งแบบอนุกรม

คำสั่งจะถูกอ่านจากมอนิเตอร์แบบอนุกรมเป็นตัวอักษรหนึ่งตัวบวกค่าตัวเลข

| สั่งการ | พิสัย | ตัวอย่าง | ความหมาย |
| --- | --- | --- | --- |
| `D<value>` | `0` ถึง `100` | `D5` | ตั้งค่าเปอร์เซ็นต์หน้าที่ของ PWM |
| `S<value>` | `0` ถึง `20` | `S2.5` | ตั้งค่าความเร็วในการหมุนด้วยไฟฟ้าเป็นองศาต่อวง |

คำสั่งแรกที่แนะนำ:

```text
D0
S1
D2
D5
```

เพิ่มหน้าที่อย่างช้าๆ ในขณะที่ดูกระแสจ่ายของบัลลังก์และรูปคลื่นของออสซิลโลสโคป

## รายการตรวจสอบการนำขึ้นมา

1. ยืนยันว่าแผนผังตรงกับแผนที่พิน PWM และ ADC ด้านบน
2. เปิดเฉพาะด้านลอจิกและตรวจสอบข้อความการบูตแบบอนุกรม
3. ขอบเขต `PA8`, `PA9`, `PA10`, `PB13`, `PB14`, และ `PB15` ก่อนที่จะเปิดใช้งานกำลังมอเตอร์
4. ยืนยันการกำหนดเวลาและเวลาตายตัวของ PWM เสริม
5. เปิดใช้งานไดรเวอร์เกตด้วยแหล่งจ่ายไฟที่มีจำกัดในปัจจุบัน
6. เริ่มต้นด้วย `D0`แล้วค่อยยกระดับหน้าที่ทีละน้อย
7. ตรวจสอบลำดับเฟสก่อนเชื่อมต่อโหลดทางกล
8. เพิ่มการตรวจจับกระแส การจัดการข้อผิดพลาด และการตอบสนองแบบวงปิดก่อนการทดสอบกำลังสูง

## หมายเหตุด้านความปลอดภัย

- ปฏิบัติต่ออินเวอร์เตอร์เสมือนเป็นฮาร์ดแวร์พลังงานสูงแม้ที่แรงดันไฟฟ้าต่ำ
